# TECHIZAT OS

🦉 **Techizat OS** - Debian Tabanlı, AI Destekli, Güvenlik Odaklı İşletim Sistemi

## 📋 Proje Özeti

Techizat OS, Parrot OS'un hafifliği ve günlük kullanılabilirliği ile Kali Linux'un kapsamlı pentest araç setini birleştiren, yapay zeka destekli, Debian tabanlı bir işletim sistemidir.

### 🎨 Tasarım Özellikleri
- **Mavi-Mor Neon Gradient** teması
- **Altıgensel geometrik tasarım** elementleri
- **Baykuş logosu** (Vizyon & İstihbarat simgesi)
- **Futuristik & Profesyonel** görünüm
- **Yüksek Kontrastlı** arayüz

## 🚀 Kurulum (Yakında)

```bash
git clone https://github.com/pikachupikapii/techizat-os.git
cd techizat-os
./build/build-iso.sh
```

## 🛠️ Teknoloji Stack
- **Base:** Debian GNU/Linux
- **Desktop:** XFCE / KDE Plasma
- **Bootloader:** GRUB 2
- **Display Manager:** LightDM
- **Theme Engine:** GTK+ 3
- **AI Support:** TensorFlow Lite, Ollama
